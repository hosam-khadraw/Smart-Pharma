Smart Pharma

An IoT system that watches medical fridges from anywhere

Real-time data in the admin dashboard

Dashboard home, dark theme

Smart Pharma makes sure corona vaccines and cures stay safe in medical stores. An ESP32 inside each fridge reports to Firebase, and the administrator and the client follow everything live.

ESP32FirebaseAdmin web appAndroid client app

Why it matters

The pandemic showed how weak the cold chain was. Many cures need steady, very low temperatures, and a power cut or an open door can ruin a whole stock.

01

Smart fridges

Central drug store refrigerators become connected: temperature, door, battery and electricity are measured and sent to the cloud.

02

Admin dashboard

A professional web app to manage clients and fridges, watch real-time data, read the history and receive error notifications.

03

Client app

An Android app lets each client check their own fridges from their phone.

How it works

From the sensors to the administrator and the client.

ESP32Reads temperature, door, battery and power
Wi-FiUploads the values with the client’s Wi-Fi settings
FirebaseRealtime Database stores data and error history
AppsAdmin web app and client Android app read it live

The admin web dashboard

One place for the administrator to manage clients and fridges and to watch every value in real time.

Design and technologies

The project followed the waterfall method, with UML diagrams drawn before any code.

What the app must do

  • Only the administrator can authenticate
  • Notify the administrator about errors
  • Add, select, modify and delete clients
  • Add, select, modify and delete each client’s fridges
  • Show real-time temperature, door, battery and power state
  • Chart the temperature and keep temperature and error history
  • Quality needs: performance, security, UX and UI, clean code

Technologies

  • Front end: HTML5, CSS3, JavaScript, FeathersJS, Chart.js
  • Data: Firebase Web SDK and Firebase Realtime Database
  • Build: Node.js and Webpack
  • Modelling: UML with Visual Paradigm
  • Embedded: ESP32 uploading the measurements to the database
